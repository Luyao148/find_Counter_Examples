# find_Counter_Examples
Find counter-examples of online programming problems.

- Use threadpool to run solutions faster.
- ListNode.h with struct ListNode for singly linked list.
- GeneUtils.h with functions to get random data.

The problems to solve in project is longest-consecutive-sequence.

https://leetcode.cn/problems/longest-consecutive-sequence/description/
